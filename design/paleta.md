# Paleta oficial da marca (definitiva)

Escolhida pelo usuário em 2026-08-06: variação marrom/terracota da logo (não a azul). Cores extraídas por amostragem de pixel direto do arquivo de logo — valores reais, não aproximação visual.

| Cor | Hex | Papel |
|---|---|---|
| Terracota | `#4C2507` | Cor principal — fundo escuro / elementos de destaque |
| Creme | `#FFFBE2` | Fundo claro / texto sobre fundo escuro |
| Dourado | `#B18C35` | Acento — ícone da lâmpada na logo, usar em detalhes/selos |

Outras variações da logo existem (azul marinho `#2C3E72`, rosa `#E9688E` — ver histórico no Canva "Logos morfe", design `DAG29BOqNtI`) mas o usuário confirmou: usar **só** as cores da versão marrom.

## Uso no catálogo web
- Terracota: cor principal (cabeçalho, títulos, preços, botões primários).
- Creme: fundo geral.
- Dourado: acento pontual (selos tipo "Mais vendido", ícone de favoritar, detalhes) — não usar como cor de fundo grande, é pra destaque.
